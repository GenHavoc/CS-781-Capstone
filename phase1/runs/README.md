# Extracted Original Runtime Sources

- `conv_runall/`: original utilities from `CS781_90M_800M_RunAll_Kaggle.ipynb`.
- `encdec_300m/`: original utilities from `CS781_EncDec_50M_300M_Kaggle.ipynb`.

Each directory contains model, preprocessing, training, generation, correctness checks and recovery/orchestration modules. The model and preprocessing files reflect the later explicit notebook cells that overwrite the initial support bundle. Source extraction uses Python AST literal parsing and base64/gzip decoding; notebook cells were not executed to recover them.

The modules retain their original local imports and are designed to run from the output directory configured by the notebook. Use the original notebook as the complete entry point. Saved run configuration, prepared datasets, tokenizer, evaluator and checkpoints are runtime artifacts rather than files automatically generated by importing these modules.

`../../docs/recovered_sources.json` records original filenames and hashes. The standalone Conv model in `../models/conv_hybrid.py` matches the recovered Conv Run-All model. The existing standalone LegalEncDec model matches its recovered notebook byte-for-byte.
